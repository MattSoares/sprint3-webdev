# Modo Estudo Inteligente

Projeto desenvolvido para a disciplina de Web Development. A aplicação funciona como uma central acadêmica para cadastrar, buscar, editar, favoritar e excluir conteúdos de estudo.

## Funcionalidades

- Cadastro de conteúdos acadêmicos;
- Busca por título ou disciplina;
- Edição e exclusão de conteúdos;
- Sistema de favoritos;
- Estatísticas de conteúdos e favoritos;
- Slideshow de materiais em destaque;
- Persistência dos dados com `localStorage`;
- Interface responsiva para computador e celular.

## Tecnologias utilizadas

- Next.js 16;
- React 19;
- JavaScript;
- HTML e CSS;
- `localStorage`;
- Git e GitHub;
- Vercel.

## Requisitos

- Node.js 20.9 ou superior;
- npm.

## Como instalar

É necessário ter o Node.js instalado. No terminal, acesse a pasta do projeto e execute:

```bash
npm install
```

## Como executar

Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

Depois, acesse `http://localhost:3000` no navegador.

## Como gerar o build

```bash
npm run build
npm start
```

## Como verificar o código

```bash
npm run lint
npm run build
```

## Autenticação

O projeto não utiliza autenticação. Portanto, não são necessários usuário e senha para realizar os testes.

## Persistência dos dados

Os conteúdos cadastrados, editados e favoritados são armazenados no `localStorage` do navegador. Os dados permanecem disponíveis mesmo depois de atualizar ou fechar a página, desde que o armazenamento do navegador não seja apagado.

## Uso de inteligência artificial

A inteligência artificial foi utilizada como ferramenta de apoio durante o desenvolvimento, principalmente na organização das ideias, no planejamento das etapas, no esclarecimento de dúvidas e na revisão de possíveis melhorias. As decisões sobre o projeto, a implementação das funcionalidades, as adaptações e os testes foram realizados e acompanhados pelos integrantes do grupo.
